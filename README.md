Classificador de Nível de Herói

Descrição do Projeto

Este projeto foi desenvolvido como parte do desafio proposto pelo
professor Felipe na plataforma DIO (Digital Innovation One). O
programa recebe o nome e a experiência (XP) de um herói de jogos e,
através de uma estrutura de tomada de decisão, classifica e exibe em
qual nível/elo o herói se encontra (de Ferro a Radiante).

Tecnologias Utilizadas

JavaScript (Lógica de programação, variáveis, operadores lógicos e
condicionais com switch case).
